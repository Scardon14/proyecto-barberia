# O&T Barbería 

## Descripción

O&T Barbería es un proyecto web desarrollado para presentar los servicios de una barbería, mostrar sus barberos y locales, y permitir a los usuarios explorar la información del negocio y acceder a la sección de reservas.

El proyecto cuenta con un diseño moderno y elegante, utilizando una paleta de colores basada en negro, rojo vino, coral, rosa claro y blanco.

## Tecnologías utilizadas

- HTML5: estructura de las páginas web.
- CSS3: estilos, diseño visual y adaptación a diferentes dispositivos.
- JavaScript: interacciones y funcionalidades de la página.
- Bootstrap 5.3.8: componentes y estilos para facilitar el diseño adaptable.

## Funcionalidades

- Página principal con imagen de fondo y presentación de la barbería.
- Sección de servicios.
- Información sobre los barberos.
- Presentación de los locales.
- Página de información sobre nosotros.
- Sección para realizar reservas.
- Página de acceso.
- Navegación entre páginas.
- Diseño adaptable a dispositivos móviles y computadores.

## Diseño visual
La identidad visual utiliza los siguientes colores:

- Negro: `#171719`
- Rojo vino: `#632F3A`
- Coral: `#C65B61`
- Rosa claro: `#E9DADC`
- Blanco: `#FFFFFF`

También se incorporaron imágenes de estilo profesional para representar los espacios, la identidad y la experiencia de O&T Barbería.

## Nota
Las reservas y el acceso son demostrativos y no cuentan con un backend conectado a una base de datos.
